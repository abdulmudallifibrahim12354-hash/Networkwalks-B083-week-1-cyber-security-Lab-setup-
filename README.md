# 🔐 Cybersecurity Lab Environment Setup

## 📌 Project Overview

This project documents my Week 1 Cybersecurity Lab Environment Setup using VirtualBox and Kali Linux.

The lab was created as a controlled environment for cybersecurity and ethical hacking practice.

## 🎯 Objectives

- Install and configure VirtualBox.
- Set up Kali Linux as the security testing machine.
- Create a NAT Network using the `10.0.0.0/24` subnet.
- Configure the Kali Linux network settings.
- Verify Internet connectivity.
- Create a snapshot of the virtual machine.

## 💻 Lab Environment

| Component | Configuration |
|---|---|
| Virtualization Platform | VirtualBox |
| Security Testing Machine | Kali Linux |
| Network Type | NAT Network |
| Network Subnet | `10.0.0.0/24` |
| Kali Linux IP | `10.0.0.2/24` |

## ⚙️ Lab Setup Process

### 1️⃣ 🛠️ VirtualBox Installation

VirtualBox was installed and configured as the virtualization platform for the cybersecurity lab.

### 2️⃣ 🐉 Kali Linux Setup

Kali Linux was downloaded and configured as the security testing machine.

### 3️⃣ 🌐 NAT Network Configuration

A NAT Network was created using the `10.0.0.0/24` subnet.

### 4️⃣ 🔧 Kali Linux Network Configuration

The Kali Linux virtual machine was configured with the required network settings.

### 5️⃣ 🌍 Internet Connectivity Test

Internet connectivity was tested from the Kali Linux virtual machine.

### 6️⃣ 📸 Virtual Machine Snapshot

A snapshot of the configured Kali Linux virtual machine was created for recovery purposes.
